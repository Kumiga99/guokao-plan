# 公考打卡计划 · 2026 国考

一个双击即可使用的打卡网页(单文件 HTML,无任何依赖,数据存在浏览器本地)。

## 功能

- 📅 15 周三阶段备考计划(模块重建 → 申论+混合 → 全真冲刺),每日任务自动按日期轮换
- ✅ 每日打卡,统计距考试天数 / 连续天数 / 本周完成度 / 里程碑鼓励
- 📝 练后小记:每天填"错几题、用几分钟",自动按模块汇总进步趋势
- 🗺️ 每周弱点地图:一周数据自动汇总(模块分布 + 错因分布),并给出下周学习方向建议
- ✍️ 复盘记录:错题卡(贴题 + 卡在哪 + 下次提醒),6 类错因可筛选

## 使用

- 电脑:下载 `打卡计划.html`,双击用浏览器打开即可
- 平板/手机:打开 GitHub Pages 网址 `https://Kumiga99.github.io/guokao-plan/`

所有数据保存在各设备浏览器的 localStorage 里,关掉重开不丢。**不同设备的数据不互通**,跨设备用页面底部的「📤 导出数据 / 📥 导入数据」按钮手动同步(合并,不会覆盖)。
